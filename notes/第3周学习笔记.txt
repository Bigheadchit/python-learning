第3周学习笔记：判断与循环

1. if / else：按条件选择
if temperature >= 40:
    print("达到或超过练习阈值")
else:
    print("低于练习阈值")

if条件成立，执行if分支；否则执行else分支。
else不代表“正确”，只表示前面的条件不成立。
40℃只是练习阈值，不能据此断言设备安全。

2. 比较与赋值
=：赋值。例如count = 0。
==：比较两个值是否相等。
>：大于；>=：大于或等于。
<：小于；<=：小于或等于。
测试边界：39.9、40、40.1，才能确认是否包含等于40。

3. for：按范围重复
for i in range(3):
    print(i)

range(3)依次提供0、1、2，共3次，不包含3。
改成range(5)就执行5次。
按一次F5启动后，循环内的input可以重复提问；每次输入后按回车。

4. while：条件成立就继续
count = 0
while count < 3:
    print(count)
    count = count + 1

count = count + 1表示旧值加1，再存回count。
这行必须在循环内；漏掉后count一直为0，循环无法正常结束。
在IDLE Shell中可用Ctrl+C中断意外的无限循环。

继续询问的写法：
answer = "y"
while answer == "y":
    # 在这里进行测试
    answer = input("输入y继续，其他内容结束：")
print("测试结束")

输入n后，下一次条件检查不成立，退出循环。

5. 缩进决定代码属于哪里
循环内代码缩进4个空格。
循环内if分支中的代码再缩进一层，共8个空格。
循环外顶格的结束提示只执行一次；放进5次循环会输出5次。

6. 时间规则修改
旧规则：duration < 0，只拒绝负数，允许0。
新规则：duration <= 0，拒绝0和负数。
提示文字也要同步修改。
计算放在else内，保证无效时间不进入计算。
无效输入也占用一次for循环，但不会结束整个循环。

7. 本周验收
5V、0.02A，分别输入-1、0、1、600、3600秒。
-1和0被拒绝；1、600、3600正常计算；最终只显示一次结束提示。
代码及提交的五组运行输出已核对正确，辅导者未代运行。

输出中的e-06表示乘以10的负6次方，例如5e-06 = 0.000005。
这是科学计数法，不是报错；无需为了显示格式修改计算。
