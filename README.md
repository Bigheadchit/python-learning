## 运行代码

我用Python 3.13.15和IDLE，打开py文件后按F5运行。第38天开始用了NumPy，本地版本是2.5.3，安装命令是：

```text
py -3.13 -m pip install numpy==2.5.3
```

CSV数据在[这里](week07/measurements.csv)。有些代码里写的是我电脑上的路径，换到别的电脑需要改一下；第30—31天读的是[这个结果文件](week05/day_results.txt)。

现在用的还是手动输入和模拟数据，Ah、Wh按电压电流不变来算。40℃只是练习判断语句时设的数值。
