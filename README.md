## 如何运行

使用 Python 3（本地学习环境为3.13.15）。这些练习仅使用内置功能，无第三方依赖。

下载代码后，用IDLE打开一个 `.py` 文件，按F5运行；出现输入提示后，填写纯数字并回车。每个练习文件独立运行。第30—31天读取第29天的结果，保留了学习时使用的文件路径；在其他电脑运行需将open中的路径改为实际下载的week05/day_results.txt位置。
