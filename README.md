## 怎么运行

我使用 Python 3.13.15 和 IDLE。打开一个 `.py` 文件，保存后按 F5；有输入提示时填写数字，再按回车。每个练习文件单独运行。

第38天起用到 NumPy，本地版本为2.5.3。在Windows命令提示符中安装：

```text
py -3.13 -m pip install numpy==2.5.3
```

CSV练习的数据在 [week07/measurements.csv](week07/measurements.csv)。部分代码保留了我电脑上的文件路径，下载后需要改成自己的路径。第30—31天读取的结果文件是 [week05/day_results.txt](week05/day_results.txt)。

## 几条备忘

- `input()`返回字符串，计算前要转换类型；转换不会自动改掉原变量。
- 列表按位置取数据，字典按键取数据。
- 修改输入后，要重新执行公式，之前算出的结果不会自动更新。
- 计算时先统一单位，再检查正常值、边界值和无效输入。

练习使用手动输入或模拟数据。40℃是编程练习阈值；目前Ah和Wh的计算假定电压、电流恒定。
